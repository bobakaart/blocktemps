Text sizes

Every other repeated text role found across all 40 blocks' own code — captions, pill badges, feedback messages, step-counter numbers, choice/option buttons, list-row text, form fields, and two small icon-glyph groups. Each was drifting between a few nearby px values doing the exact same job in different blocks; now one value per role, everywhere. A few genuine one-off design elements (the 52px animated counter, Word Unscramble's letter tiles, decorative background glyphs) were deliberately left alone — those are the actual design of that specific block, not a repeated role. Buttons

One shape and color set for every Submit / Check / Next / Reset / Try Again button across all 40 blocks — change it once here instead of per block. Primary buttons (Submit, Check, Next) use a solid fill; secondary buttons (Reset, Try Again) use an outline — both share the same size/shape below, and their colors default to matching Primary color / Text color but are fully independent, so buttons can look different from the rest of the UI if you want that.
